# NepaliLLM-Eval

A benchmark suite for Nepali language models. Each category is a JSONL file
with curated records (human-written, sourced, license-tracked). Records
contain a `prompt`, one or more `answer`s, optional `distractors`, and
metadata for provenance.

| Category | File | Items | Measures |
|---|---|---|---|
| Factual cloze | `ne_cloze.jsonl` | 40 | World knowledge (Nepal geography, history, culture) |
| Grammar | `ne_grammar.jsonl` | 30 | Verb conjugation, case markers, tense, postpositions |
| Commonsense | `ne_commonsense.jsonl` | 25 | Everyday reasoning grounded in Nepali culture |
| Translation | `ne_translation.jsonl` | 20 | Nepali↔English paired translation |
| Summarization | `ne_summarization.jsonl` | 10 | Passage→summary reference quality |
| Wikipedia QA | `ne_wiki_qa.jsonl` | 20 | Factual QA from Nepal-related Wikipedia articles |
| **Total** | | **145** | |

## Scoring

All categories use **selection scoring**: the model is given the prompt and
scores each candidate (answers + distractors) by conditional
log-probability. The candidate with the highest total score is "the model's
answer"; it is correct if it matches a reference answer. This measures
knowledge *without* requiring the model to produce fluent text.

Future work: `generative` mode (greedy decode + exact/fuzzy match) for
summarization and translation.

## Running

```bash
# Native NepaliGPT checkpoint
python scripts/eval_benchmark.py --ckpt ckpt/best.pt --tok tokenizer/nepali_bpe.model

# Hugging Face baseline (e.g. mGPT)
python scripts/eval_benchmark.py --model ai-forever/mGPT

# Specific categories only
python scripts/eval_benchmark.py --benchmarks ne_cloze ne_grammar

# All categories, compare two models
python scripts/eval_benchmark.py --model ai-forever/mGPT > eval/results/mgpt_benchmark.txt
python scripts/eval_benchmark.py --ckpt ckpt/best.pt > eval/results/nepaligpt_benchmark.txt
```

Each run writes a timestamped JSON report to `eval/results/`.

## Benchmark design principles

1. **Human-curated**: Each record is hand-written, not extracted
   mechanically from a corpus or generated by another LLM.
2. **License-tracked**: Every record carries `source` and `license` fields.
   Curated items are marked `CC BY-SA 4.0` where derived from Wikipedia
   content or released under that license by the author.
3. **No training-data contamination**: Records are *not* drawn from the
   NepaliGPT training corpus, so benchmark scores are not inflated by
   memorization.
4. **Culturally grounded**: Nepali-specific facts (the only country with a
   double-triangular flag, Rara being the largest lake, etc.) that a
   generic multilingual model is unlikely to know well.
5. **Multiple answers**: Where valid, multiple synonyms/paraphrases are
   accepted (`"काठमाडौं"` and `"पाटन"` for Lalitpur, etc.).

## Contributing

To add records, follow the existing JSONL schema:

```json
{
  "id": "category_NNN",
  "task": "cloze",
  "prompt": "नेपालको राजधानी",
  "answer": ["काठमाडौं"],
  "distractors": ["पोखरा", "विराटनगर", "धरान"],
  "category": "geography",
  "source": "curated",
  "license": "CC BY-SA 4.0"
}
```

Rules:
- `id` must be unique within a file.
- `answer` must be non-empty; `distractors` optional but recommended for
  selection scoring.
- `source` and `license` are required.
- Nepali text should use Devanagari script and be grammatically correct.
